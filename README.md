# 📝 Archive

A modern, high-performance blog application built with **Vue 3** and **Vite**. This project demonstrates essential Vue patterns including dynamic routing, asynchronous component handling, and robust error management.

---

## Key Features

- **Dynamic Routing:** Seamless navigation between the Home feed and individual Post Detail pages.
- **API Data Fetching:** Real-time data retrieval for blog titles and content.
- **Lazy Loading & Suspense:** Optimized performance using Vue's `<Suspense>` for async components.
- **Error Boundaries:** Graceful handling of component-level crashes via `onErrorCaptured`.
- **404 Fallback:** A dedicated "Not Found" page for non-existent routes.
- **Navigation Control:** Users can return to the Home page or the previous page from any view.

---

## Tech Stack

| Tool | Purpose |
| :--- | :--- |
| **Vue 3** | Core Framework (Composition API & `<script setup>`) |
| **Vite** | Next-generation Frontend Tooling |
| **Vue Router 4** | Single Page Application Navigation |
| **JSONPlaceholder** | Placeholder API for blog data fetching |
